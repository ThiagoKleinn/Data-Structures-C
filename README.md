# Data Structures in C

Repositório com implementações de estruturas de dados desenvolvidas em linguagem C, com foco em aprendizado acadêmico e prática de lógica de programação.

## Estruturas implementadas

- Linked List (Lista Encadeada)
- Queue (Fila Encadeada)
- Stack (Pilha Encadeada)
- Deque (Fila Dupla)

## Conceitos aplicados

- Manipulação de ponteiros
- Alocação dinâmica
- Estruturas lineares
- Organização modular de código
- Boas práticas em C

## Objetivo

Este projeto foi criado para reforçar conceitos fundamentais de Estruturas de Dados, muito utilizados em algoritmos, sistemas e entrevistas técnicas.
